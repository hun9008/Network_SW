# 실행 설명서

## 과제 2-1

### Server
```
./thread_udp_server.exe
```

서버는 terminal에 출력되는 설명대로 키보드입력을 통해 통계정보 확인 가능.

### Client
```
./client_udp.exe 127.0.0.1 9000
```

이후 Client는 닉네임과 전송할 메세지 입력.
