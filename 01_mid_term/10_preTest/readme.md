# 네트워크 프로그래밍 중간고사 문제 구성

---

## 문제 1: UDP 소켓을 이용한 메시지 송수신

**주제:** 기본적인 UDP 서버-클라이언트 구성  
**설명:** UDP 소켓을 사용해 클라이언트가 서버에 메시지를 보내고, 서버는 해당 메시지를 그대로 에코합니다.  
**의의:** UDP 소켓의 송수신 이해를 기반으로, 문제 2에서 TCP로 확장합니다.  

---

## 문제 2: TCP 서버로의 확장 및 다중 클라이언트 처리

**의존성:** 문제 1의 UDP 기반 메시지 송수신이 완료되어야 함.  
**주제:** TCP 프로토콜을 사용해 여러 클라이언트를 동시 처리하는 서버 개발  
**설명:**  
- 문제 1에서 구현한 기능을 TCP 소켓으로 확장합니다.  
- 여러 클라이언트를 동시에 처리하기 위해 `fork()` 또는 스레드를 사용해 각 클라이언트를 개별적으로 처리합니다.  
**의의:** TCP와 다중 접속 처리를 이해한 후, 문제 3에서 비동기 I/O를 사용한 고급 소켓 프로그래밍으로 확장합니다.

---

## 문제 3: 비동기 소켓과 소켓 옵션 활용

**의존성:** 문제 2에서 TCP 기반 다중 클라이언트 처리가 구현되어야 함.  
**주제:** 소켓 옵션 설정과 비동기 방식의 클라이언트 처리  
**설명:**  
- TCP 서버에 소켓 옵션 `SO_REUSEADDR`을 설정합니다.  
- 서버에서 `select()` 또는 `poll()`을 사용해 다중 클라이언트를 비동기적으로 처리합니다.  
**의의:** 고급 소켓 처리 방식을 이해하고, 문제 4에서 파일 전송 프로토콜(TFTP) 구현으로 확장합니다.

---

## 문제 4: TFTP 프로토콜을 이용한 파일 전송

**의존성:** 문제 3의 비동기 소켓 처리와 옵션 활용이 완료되어야 함.  
**주제:** TFTP 프로토콜 기반 파일 송수신 구현  
**설명:**  
- RFC1350 규격에 맞추어 TFTP 서버와 클라이언트를 구현합니다.  
- 클라이언트가 요청한 파일을 서버가 512바이트 조각 단위로 전송합니다.  
**의의:** 모든 문제를 종합한 응용 서비스를 구현하며, 네트워크 프로그래밍의 개념과 응용 능력을 평가합니다.
